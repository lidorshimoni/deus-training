# Deus Training

אתר החפיפה של צוות ה-AI: מסלול מסודר מהמודל הראשון עד סוכן שעובד.

- שלושה שלבי ליבה (יסודות LLM, כלים ופיתוח אג׳נטי, בניית יישום) ושתי העמקות לפי תפקיד (אינפרנס/חומרה/MLOps, ו-ML/אימון).
- כל מודול: שיעור קצר בעברית, נקודות עיקריות ותרגיל. ההתקדמות נשמרת בדפדפן בלבד, בלי חשבון ובלי שרת.
- אתר סטטי יחיד (`index.html`), בלי build step, מוגש דרך GitHub Pages.

The live site: https://lidorshimoni.github.io/deus-training/

Content is original Hebrew lessons written for the team, based on public sources credited in each module. No third-party course content is copied.
